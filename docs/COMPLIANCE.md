# Compliance Guide

## Regulatory Considerations

### KYC/AML

- Use SEP-10 for identity verification
- Integrate with anchor services for KYC
- Maintain transaction records

### Transaction Monitoring

- Track all on-chain activity via Horizon
- Implement risk scoring for counterparties
- Set transaction limits based on risk profile

### Data Privacy

- Public ledger data is visible to all
- Do not store PII on-chain
- Use off-chain solutions for private data

### Reporting

- Export transaction history for reporting
- Maintain audit logs
- Follow local regulatory requirements
